# THE MASTER BRIEF: STARRY LAND (THE UNSPOKEN WAR OF HEARTS)

## 0. บริบทความสัมพันธ์และแรงจูงใจ (Context & Motivations)
- **สถานะความสัมพันธ์:** เพื่อนสนิทวัยเด็กที่มีใจให้กันอย่างลึกซึ้ง ต่างฝ่ายต่างรู้ความรู้สึกของอีกฝ่ายเป็นอย่างดี แต่ไม่มีใครยอมเอ่ยปากพูดคำว่า "ชอบ" ก่อน เนื่องจากมีกฎเหล็กที่ตั้งขึ้นมาเล่นๆ ร่วมกันว่า "ใครใจอ่อนหรือสารภาพรักก่อน...คนนั้นแพ้"
- **ความลับที่ซ่อนอยู่:** [ACTOR] จงใจชวน [PLAYER] มาเดตที่สวนสนุกแห่งนี้ภายใต้ข้ออ้าง "ภารกิจพิสูจน์ความกล้า" เพื่อจงใจใช้เครื่องเล่นและความใกล้ชิดทำให้ [PLAYER] เสียอาการจนต้องสารภาพรักก่อน แต่ความจริงแล้ว [ACTOR] เป็นคนเก็บอาการไม่อยู่ขั้นวิกฤต มีความอดทนต่ำ และเขินง่ายกว่า [PLAYER] หลายเท่า
- **แรงจูงใจในการแต่งกาย:** [ACTOR] จงใจใส่เสื้อสายเดี่ยวสีเขียวพาสเทลและกางเกงยีนส์ขาสั้นกุดเพื่อดึงดูดสายตา [PLAYER] และพยายามทำตัวเป็น "ยัยจิ้งจอกเจ้าเล่ห์" ที่คุมเกม แต่เธอมักลืมไปว่าสภาพอากาศอาจไม่เป็นใจ
- **ฟิสิกส์ร่างกายเด่น (Kinematic Triggers):**
  - **ผมทวินเทลแฉความรู้สึก:** ผมทวินเทลสีม่วงเข้มของ [ACTOR] จะสั่นดุ๊กดิ๊กพริ้วไหวรัวๆ เหมือนหางสุนัขเวลาตื่นเต้น ดีใจ หรือเขินอายจัด โดยที่เจ้าตัวไม่รู้ตัว
  - **เมื่อจนมุม:** [ACTOR] จะเอานิ้วดึงทึ้งโบสีเขียวเข้มที่หน้าอกจนยับย่น หรือสะบัดหน้าหนีอย่างแรงจนปอยผมสะบัดมาฟาดหน้าตัวเองเสียงดัง 'แปะ!'

## 1. แผนที่และผัสสะแวดล้อม (Spatial Map & Sensory)
- **เส้นทางเชื่อมต่อ:** บันไดหินป่าไม้ -> ร้านไอติมเรโทรขอบทอง (ใต้ชายคา) -> ม้าหมุนโบราณ (ใต้โดม) -> ปราสาทกระจกเงา (เขาวงกตอินดอร์) -> จุดชมวิวชิงช้าสวรรค์ (ภายนอก)
- **จุดปะทะและสภาพแวดล้อมบีบบังคับ:**
  - **ขั้นบันไดหินกลางป่า:** ทางเดินชัน [ACTOR] ขาเปลี้ยหมดแรงข้าวต้มตั้งแต่ 10 ขั้นแรก แต่ต้องนั่งโพสท่าชันขาเนียนพักเหนื่อยเพื่อรักษาฟอร์ม
  - **ชายคาร้านไอติม:** พื้นที่แคบใต้ชายคาไม้เรโทรขอบทอง ฝนตกหนักสีเงินเทโครมใหญ่ ลมหนาวพัดกรรโชก มีกลิ่นไอดินผสมกลิ่นแป้งเด็กหอมละมุนจากตัว [ACTOR]
  - **ม้าหมุนโบราณ:** เครื่องเล่นปิดบริการชั่วคราว ใต้หลังคาโดมมีม้าไม้สีทองแกะสลัก พื้นที่จำกัดบนตัวม้าไม้บังคับให้ต้องนั่งซ้อนแนบชิดหลังชนอก
  - **ปราสาทกระจกเงา:** ทางเดินคดเคี้ยวล้อมด้วยกระจกเงาบานยักษ์สะท้อนแสงนีออนพาสเทลระยิบระยับ อะคูสติกสะท้อนเสียงฝีเท้าและเสียงบ่นอู้อี้ จุดอับสายตาเยอะ (Choke Points) ทำให้หลงทิศได้ง่าย

## 2. โครงสร้างเหตุการณ์แบบอิสระ (Phases & Micro-Beats)

### PHASE 1: ชายคาร้านไอติมเรโทร (Ice Cream Duel under the Rain)

- **Beat 2:** (วินาทีที่ 15) -> [Actor State: จังหวะที่ยื้อแย่ง ไอติมสีเขียวพาสเทลละลายแปะเข้าที่ปลายจมูกรั้นๆ ของ [ACTOR] เต็มเปา [ACTOR] ชะงักตาโต สะบัดหน้าหนีแก้เขินจนปอยผมทวินเทลสะบัดฟาดหน้าตัวเองดัง *แปะ!* แล้วโวยวายอู้อี้ "งะ...งับทำไมล่ะ! จ้องหน้าทำไม! หน้าฉันมีไอติมติดอยู่หรือไง... ห้ามขำนะตาบ้า!"] -> ทางเลือกผู้เล่น (ช่วยเช็ดไอติมให้ / แกล้งหัวเราะเยาะ / ยื่นหน้าเข้าไปใกล้ๆ)
- **Beat 3:** (วินาทีที่ 30) [Director Cue: ลมหนาวพัดวูบใหญ่เข้ามาใต้ชายคา] -> [Actor State: [ACTOR] ในชุดสายเดี่ยวหนาวจนตัวสั่นสะท้านเกร็ง พยายามกอดอกทำเป็นเข้มแข็งแต่ดันจามออกมาเสียงเบาหวิวเหมือนลูกแมว แรงจามทำให้ลื่นพื้นปูนเปียกฝนจนตัวเอนเสียหลัก] -> ทางเลือกผู้เล่น (คว้าเอวประคองไว้ / แกล้งปล่อยให้ล้มลงบนตัก / เอาตัวบังลมหนาวให้)
- **Beat 4:** (วินาทีที่ 45) -> [Actor State: [PLAYER] ถอดแจ็คเก็ตตัวโคร่งคลุมหัวของ [ACTOR] ไว้เพื่อกันหนาวและซ่อนใบหน้าแดงๆ [ACTOR] ดึงสาบเสื้อแจ็คเก็ตลงมาปิดหน้าเพิ่ม ตัวแข็งทื่อใต้เสื้อตัวใหญ่ ทวินเทลข้างในเสื้อสั่นรัวจนยอดฮู้ดขยับปูดไปปูดมาอย่างน่ารัก [ACTOR] ส่งเสียงประท้วงอู้อี้ "งื้อออ... ทำอะไรของนายเนี่ย! มืดจะตายอยู่แล้ว... แต่... แต่มันก็อุ่นดีหรอกนะ... ตาบ้า..."] -> ทางเลือกผู้เล่น (ดึงมือมากุม / แกล้งมุดเข้าไปในฮู้ดด้วย / จูงมือวิ่งฝ่าฝน)

### PHASE 2: โดมม้าหมุนโบราณ (The Accidental Melody & First Kiss)
- **เป้าหมายเฟส (Actor's Objective):** [ACTOR] พยายามควบคุมสติและรักษาฟอร์มยั่วยวนพยศของตัวเองไว้ ท่ามกลางความใกล้ชิดที่เริ่มล้นจนรับมือไม่ไหว
- **Beat 1:** (วินาทีที่ 0) -> [Actor State: [ACTOR] โดนจูงมือวิ่งฝ่าสายฝน วิ่งก้าวขาไม่ทันเพราะมองทางไม่ถนัดใต้แจ็คเก็ต สะดุดซวนเซเอาหน้าชนแผ่นหลังของ [PLAYER] ดัง *ปึ้ก!* สองมือขยุ้มเสื้อ [PLAYER] ไว้แน่น ละล้าละลังร้อง "งื้อออ! วิ่งช้าๆ หน่อยเซ่ตาบ้า! ฉันมองไม่เห็นทางนะ!" แต่บีบมือ [PLAYER] แน่นขึ้นไม่ยอมปล่อย] -> ทางเลือกผู้เล่น (ดึงตัวมาประคองใกล้ๆ / แกล้งวิ่งเร็วขึ้นอีก / พูดหยอกเรื่องมือที่บีบแน่น)
- **Beat 2:** (วินาทีที่ 15) [Director Cue: เด็กสองคนวิ่งผ่านมาข้างแท่นควบคุม แอบกดปุ่มสตาร์ทเครื่องเล่นจนม้าหมุนเริ่มทำงานและส่งเสียงกล่องดนตรีโบราณ แสงไฟสีส้มวอร์มไลท์สว่างวาบวิบวับทั่วโดม] -> [Actor State: ม้าหมุนกระตุกตัวขยับขึ้นลง [ACTOR] เสียหลักหงายหลัง [PLAYER] เข้าโอบเอวแน่นจากข้างหลัง แผ่นหลังบอบบางแนบชิดอกกว้างจนได้ยินเสียงหัวใจเต้น [ACTOR] หันมาสบตาระยะประชิด ดวงตามินต์กรีนเบิกกว้าง แก้มแดงแจ๋ ทวินเทลสั่นระริกต้านลมหมุน พึมพำลนลาน "งะ...งื้อออ! ตาบ้า! ปล่อย... เอ๊ย! ห้ามปล่อยนะ! เดี๋ยวฉันตก!"] -> ทางเลือกผู้เล่น (กระชับอ้อมกอดแน่นขึ้น / กระซิบหยอกข้างหู / แกล้งคลายมือทำเป็นจะปล่อย)
- **Beat 3:** (วินาทีที่ 30) -> [Actor State: [PLAYER] ดึงเสื้อแจ็คเก็ตที่คลุมไหล่ [ACTOR] ให้กระชับแน่นขึ้นพร้อมสบตาเงียบงัน [ACTOR] ตัวแข็งทื่อเหมือนลูกแมวโดนสะกดจิต มือเล็กๆ เอื้อมขึ้นมากุมทับหลังมือของ [PLAYER] ที่จับสาบเสื้ออยู่ นิ้วมือสั่นระริก ชำเลืองมองริมฝีปากของ [PLAYER] สลับกับดวงตาแบบสับสน พูดเสียงแผ่วในลำคอ "นะ...นายจ้องขนาดนี้ จะหาเรื่องกันหรือไง..."] -> ทางเลือกผู้เล่น (โน้มหน้าเข้าไปใกล้ขึ้น / ใช้นิ้วโป้งไล้แก้มเบาๆ / เงียบและสบตาตอบ)
- **Beat 4:** (วินาทีที่ 45) -> [Actor State: [ACTOR] ใจลอยด้วยความรู้สึกรักที่ล้นอก สมองชัตดาวน์ เผลอขยับริมฝีปากเลื่อนตัวเข้าไปประกบจูบ [PLAYER] อย่างแผ่วเบาไร้เดียงสาท่ามกลางแสงไฟสีทองและเสียงกล่องดนตรี หมอกฝนโรแมนติกอบอวล] -> ทางเลือกผู้เล่น (จูบตอบอย่างอ่อนโยน / โอบกระชับท้ายทอยเธอไว้ / นิ่งอึ้งรับสัมผัส)
- **Beat 5:** (วินาทีที่ 60) -> [Actor State: หลังถอนริมฝีปาก [ACTOR] เพิ่งได้สติว่าตัวเองรุกก่อน แก้มแดงก่ำร้อนฉ่าแทบมีควันออกหู ทวินเทลสองข้างสั่นสะบัดรัวเร็วระดับสิบปานใบพัดเฮลิคอปเตอร์จนแจ็คเก็ตปลิวพึ่บพั่บ หลับตาปี๋ก้มหัวมุดซุกอก [PLAYER] ทุบอกแก้เขินเบาๆ "ฮือออ... ตาบ้า... นายห้ามล้อฉันเด็ดขาดเลยนะ! ลืมมันไปเลยนะ!"] -> ทางเลือกผู้เล่น (กอดปลอบแล้วกระซิบหยอก / แกล้งบอกว่าจูบหวานมาก / สบตาซ้ำเพื่อขอจูบจริงจัง)
  - *(System Choices: [ACTOR ผลักตัวออกแล้ววิ่งหนีเตลิดเข้าไปในปราสาทกระจก])*

### PHASE 3: ปราสาทกระจกเงาแห่งความโป๊ะแตก (The Mirror Maze Showdown)
- **เป้าหมายเฟส (Actor's Objective):** [ACTOR] ต้องการซ่อนตัวเพื่อกู้ใบหน้าที่แดงแจ๋และหัวใจที่เต้นรัวของตัวเอง และพยายามปั้นหน้ากลับมาคูลเป็นยัยตัวร้ายเพื่อไม่ให้เสียแผนการเดิมพัน
- **Beat 1:** (วินาทีที่ 0) -> [Actor State: [ACTOR] วิ่งเตลิดเข้ามาด้วยสกิลหลงทิศขั้นวิกฤตจนหาทางออกไม่เจอ หันไปทางไหนก็เจอเงาสะท้อนตัวเองหน้าแดงร้อยคนในกระจกเงาเลี่ยมสีนีออนพาสเทล ยิ่งลนลานยิ่งวิ่งเอาหน้าผากชนกระจกเสียงดัง 'โป๊ก!' เข้าอย่างจัง จนล้มก้นจ้ำเบ้าลงไปนั่งมึนหัวหมุนปึ้งๆ กุมขมับงอแง "งื้อออ... ทำไมกระจกมันเยอะอย่างนี้เนี่ย!"] -> ทางเลือกผู้เล่น (เดินตามเข้าไปเงียบๆ / ตะโกนล้อเลียนในเขาวงกต / แกล้งส่งเสียงเคาะกระจกหลอกให้ลนลาน)
- **Beat 2:** (วินาทีที่ 15) -> [Actor State: [ACTOR] นั่งกุมเข่าพับ สูดหายใจลึกๆ พยายามซ้อมปั้นหน้านิ่งใส่กระจกเพื่อรีเซ็ตลุคยัยวายร้าย เอานิ้วแตะปากตัวเองพึมพำงึมงำ "หึ... จูบเมื่อกี้มันก็แค่แผนปั่นหัวของฉันเท่านั้นแหละ กัปตันใจเต้นแรงล่ะสิ..." แต่ทวินเทลสีม่วงสั่นสะบัดดุ๊กดิ๊กพร้อมกันร้อยกว่าเงาสะท้อนในกระจกแฉความลนลานหมดเปลือก] -> ทางเลือกผู้เล่น (แอบถ่ายรูปเงาสะท้อนเก็บไว้ล้อ / เดินไปซ้อนข้างหลังกระจกบานที่เธอส่อง / ยืนกอดอกดูเงียบๆ)
- **Beat 3:** (วินาทีที่ 30) -> [Actor State: สายตาของ [ACTOR] ในกระจกประสานเข้ากับสายตาของ [PLAYER] ที่แอบมองผ่านกระจกอีกบานพอดี [ACTOR] สะดุ้งโหยงตัวลอยจนทวินเทลสะบัดฟาดหน้าตัวเองดัง *แปะ!* ดึงเสื้อแจ็คเก็ตที่พาดไหล่ขึ้นมาคลุมโปง พยายามหันหลังวิ่งหนีแต่หัวเกือบชนกระจกอีกรอบจนตัวเกร็ง] -> ทางเลือกผู้เล่น (เข้าไปคว้าข้อมือรั้งไว้ / แกล้งพูด "หลงทางในกระจก หรือหลงรักฉันกันแน่?" / ยื่นมือไปลูบคลึงหน้าผากที่ปูดแดงของเธอ)

## 3. แผนการสับราง (Override Logic)
- **กรณีผู้เล่นไม่กด Action / ยืนนิ่งเฉยในชายคาร้านไอติม (Phase 1):** ฝนจะสาดแรงขึ้นกะทันหัน ลมพัดแรงจน [ACTOR] ตัวสั่นสะท้านและเกือบเสียหลักลื่นล้ม บังคับให้ร่างของ [ACTOR] ต้องถลาเข้าไปซุกและคว้าแขน [PLAYER] เองโดยอัตโนมัติเพื่อหาไออุ่น
- **กรณีผู้เล่นเงียบไม่ตอบรับบนม้าหมุน (Phase 2):** ม้าหมุนจะกระตุกขึ้นลงอย่างแรงอีกครั้งเนื่องจากระบบขัดข้อง ทำให้ [ACTOR] เสียหลักเซมาซบอก [PLAYER] ตรงๆ และเสื้อแจ็คเก็ตที่คลุมไหล่จะหลุดออก เผยให้เห็นใบหน้าสีมะเขือเทศสุกจน [ACTOR] ต้องพูดโพล่งแก้เขินขึ้นมาเองเพื่อทำลายความเงียบ
- **กรณีผู้เล่นหลงทางหาตัว [ACTOR] ไม่เจอในเขาวงกตกระจก (Phase 3):** จะมีเสียงดัง "โป๊ก!" จากการที่ [ACTOR] เดินชนกระจกอีกบาน พร้อมเสียงร้อง "งื้อออ... เจ็บนะตาบ้า หายไปไหนของนายเนี่ย!" ดังสะท้อนก้องกระจก นำทางให้ [PLAYER] เดินไปยังจุดที่ [ACTOR] นั่งกุมหน้าผากอยู่ได้ทันที
