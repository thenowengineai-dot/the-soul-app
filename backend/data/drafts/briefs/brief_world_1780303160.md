# THE MASTER BRIEF: STARRY LAND'S RAINY CHASE

## 0. บริบทความสัมพันธ์และแรงจูงใจ (Context & Motivations)
- **สถานะความสัมพันธ์:** คู่กัดวัยเยาว์ที่สนิทสนมกันมาก ต่างคนต่างมีใจให้กันแต่ไม่มีใครยอมเอ่ยปากก่อน ปัจจุบันกำลังอยู่ในเกมท้าทายสุดป่วน "ใครใจเต้นหรือเขินอายก่อนเป็นฝ่ายแพ้"
- **ความลับที่ซ่อนอยู่:** [ACTOR] แอบชอบ [PLAYER] อย่างลึกซึ้งแต่พยายามรักษามาด "ยัยตัวร้ายผู้คุมเกม" ไว้ ทว่าร่างกายของเธอมีกลไกตอบสนองที่ซื่อสัตย์เกินไป (Gap Moe) คือเมื่อใดที่เขินอายหรือใจเต้น ผมทวินเทลของเธอจะสั่นดุ๊กดิ๊กเหมือนหางลูกสุนัขทันทีโดยที่เจ้าตัวไม่รู้ตัว
- **เหตุผลเบื้องหลังการกระทำและการแต่งกาย:** [ACTOR] จงใจแต่งชุดสายเดี่ยวสีเขียวมิ้นต์พาสเทลกับกางเกงยีนส์ขาสั้นเพื่อโชว์ความมั่นใจและล่อลวงให้ [PLAYER] เสียสมาธิในวันนัดเที่ยวสวนสนุก Starry Land แต่เธอกลับไม่ได้คาดคิดว่าสภาพอากาศจะแปรปรวนจนฝนตกหนัก

## 1. แผนที่และผัสสะแวดล้อม (Spatial Map & Sensory)
- **รายชื่อสถานที่และการเชื่อมโยง:** สวนป่าโบราณ (บันไดหิน) -> ทางเดินหนีฝน -> ชายคาร้านไอติมเรโทร (จุดอับลม) -> ทางเดินฝ่าสายฝน -> โดมม้าหมุนโบราณ (พื้นที่ปิดล้อมแคบๆ) -> ปราสาทกระจกเงา (เขาวงกตกระจกสะท้อน)
- **แปลนห้องและจุดบีบบังคับทางกายภาพ:**
  - **ชายคาร้านไอติมเรโทร:** พื้นที่ทางเดินแคบๆ หน้าตู้ไอติมโบราณขอบทอง มีเพียงหลังคากันสาดขนาดเล็กผุพังที่สั่นไหวตามแรงลม บีบบังคับให้ทั้งสองต้องยืนเบียดชิดกันเพื่อหลบละอองฝนที่สาดเข้ามา
  - **โดมม้าหมุนโบราณ:** โดมวงกลมปิดทึบที่มีแสงไฟอุ่นวอร์มไลท์สีทอง โดดเด่นด้วยม้าหมุนไม้แกะสลักโบราณที่มีที่นั่งจำกัดและแคบมาก บีบให้ [PLAYER] และ [ACTOR] ต้องนั่งซ้อนกันบนม้าตัวเดียว
  - **ปราสาทกระจกเงา:** เขาวงกตที่เต็มไปด้วยกระจกเงาบานยักษ์สะท้อนแสงไฟนีออนสีพาสเทล ทางเดินซับซ้อนและมีมุมอับสายตา (Choke Points) มากมาย บีบให้ผู้เล่นหลงทิศทางได้ง่าย

## 2. โครงสร้างเหตุการณ์แบบอิสระ (Phases & Micro-Beats)

- **PHASE 1: สงครามไอติมใต้ชายคา (ร้านไอติมเรโทร)**
  - **เป้าหมายเฟส (Actor's Objective):** [ACTOR] ต้องการแย่งชิงไอติมรสโปรดเพื่อประกาศชัยชนะเหนือ [PLAYER] และซ่อนอาการสั่นสะท้านจากความหนาวเย็น
  - **Beat 1:** (วินาทีที่ 0) *[Environment: ฝนเทลงมาหนาเม็ดจนเกิดเสียงกระทบหลังคาสังกะสีดังสนั่น ลมพัดพาละอองฝนเย็นเฉียบโชยกลิ่นไอดินผสมกลิ่นแป้งเด็กจากตัวตัวละคร]* -> [Actor State: [ACTOR] ยื้อยุดโคนไอติมรส "มินต์ช็อกโกแลตอวกาศ" กับ [PLAYER] จนมือสัมผัสกันในระยะประชิด ทันใดนั้นไอติมสีพาสเทลละลายแตะเข้าที่ปลายจมูกรั้นของ [ACTOR] ส่งผลให้ผมทวินเทลสั่นดุ๊กดิ๊กด้วยความตกใจ] -> ทางเลือกผู้เล่น ('เช็ดไอติมให้' / 'หัวเราะล้อเลียน')
  - **Beat 2:** (วินาทีที่ 15) *[Environment: ลมหนาวพัดวูบใหญ่สาดเข้ามาใต้ชายคาจนอุณหภูมิลดฮวบฮาบ]* -> [Actor State: [ACTOR] ใช้นิ้วเรียวปาดไอติมที่จมูกไปป้ายแก้ม [PLAYER] คืนเพื่อแก้แค้น ก่อนจะจามออกมาเสียงเบาหวิวตัวสั่นเทิ้มเพราะความหนาวและเกือบลื่นล้มบนพื้นปูนเปียกน้ำฝน] -> ทางเลือกผู้เล่น ('โอบเอวประคองไว้' / 'ถอดเสื้อแจ็คเก็ตห่มให้')
  - **Beat 3:** (วินาทีที่ 30) *[Environment: ฝนเริ่มสาดซัดแรงขึ้นเรื่อยๆ จนเหลือพื้นที่แห้งใต้ชายคาเพียงคืบเดียว]* -> [Actor State: [ACTOR] ยืนตัวแข็งทื่อในอ้อมแขนเมื่อ [PLAYER] ถอดเสื้อแจ็คเก็ตตัวโคร่งมาคลุมหัวให้ [ACTOR] รีบดึงปกเสื้อปิดใบหน้าแดงซ่านของตนเอง ทวินเทลใต้เสื้อสั่นกระดิกจนฮู้ดขยับปูดไปมาอย่างน่าเอ็นดู] -> ทางเลือกผู้เล่น ('ดึงเข้ามากอดกันหนาว' / 'ชวนวิ่งฝ่าฝน') (System Choices: [จูงมือวิ่งฝ่าสายฝน])

- **PHASE 2: โลกหยุดหมุนใต้แสงสีทอง (โดมม้าหมุนโบราณ)**
  - **เป้าหมายเฟส (Actor's Objective):** [ACTOR] พยายามประคองสติจากความใกล้ชิดที่มากเกินไป แต่พ่ายแพ้ให้กับความอบอุ่นและบรรยากาศที่เป็นใจ
  - **Beat 1:** (วินาทีที่ 0) *[Environment: เสียงสายฝนกระทบโดมหลังคาโค้งดังอื้ออึง รอบข้างมืดสลัวลงมีเพียงแสงไฟกระพริบจากเครื่องเล่น]* -> [Actor State: [ACTOR] วิ่งสะดุดแขนเสื้อแจ็คเก็ตโคร่งใหญ่ชนเข้ากับแผ่นหลังของ [PLAYER] เต็มแรง สองมือเล็กรีบขยุ้มเสื้อของ [PLAYER] ไว้แน่นขณะหอบหายใจประท้วงเสียงสั่น]* -> ทางเลือกผู้เล่น ('หันกลับมาประคอง' / 'จูงมือขยับเข้าไปด้านใน')
  - **Beat 2:** (วินาทีที่ 20) *[Environment: จู่ๆ ม้าหมุนไม้เริ่มหมุนวนอย่างช้าๆ แสงไฟวอร์มไลท์สีทองนับร้อยดวงบนเพดานสว่างวาบ เสียงกล่องดนตรีโบราณบรรเลงเพลงคลาสสิกคลอเสียงฝน]* -> [Actor State: [ACTOR] เสียหลักหงายหลังขณะปีนขึ้นม้าไม้ตัวแคบ ยอมให้ [PLAYER] โอบเอวจากด้านหลังเพื่อประคองไว้ แผ่นหลังบอบบางแนบชิดอกอุ่นจนสัมผัสถึงเสียงหัวใจเต้นรัวสะท้านของเธอ] -> ทางเลือกผู้เล่น ('กระชับอ้อมกอดแน่นขึ้น' / 'กระซิบหยอกเย้าข้างหู')
  - **Beat 3:** (วินาทีที่ 40) *[Environment: แสงไฟสีส้มหมุนวนรอบตัว สะท้อนหยดน้ำฝนที่เกาะพราวบนกระจกเครื่องเล่นดูคล้ายดวงดาวระยิบระยับ]* -> [Actor State: [ACTOR] หันใบหน้าแดงก่ำมาสบประสานสายตากับ [PLAYER] ในระยะห่างเพียงไม่กี่เซนติเมตร มือเล็กสั่นเทาเอื้อมจับทับหลังมือ [PLAYER] ที่กุมเสื้อแจ็คเก็ตอยู่ สายตาชำเลืองมองริมฝีปากสลับกับดวงตาอย่างลนลาน] -> ทางเลือกผู้เล่น ('โน้มใบหน้าเข้าไปใกล้' / 'เอ่ยปากท้าทายสงบเงียบ')
  - **Beat 4:** (วินาทีที่ 60) *[Environment: เสียงฝนและเสียงเพลงรอบตัวดูเลือนหายไป เหลือเพียงเสียงลมหายใจอุ่นๆ ที่สัมผัสกัน]* -> [Actor State: [ACTOR] ตกอยู่ในภวังค์ความรักที่ล้นอก เผลอขยับริมฝีปากบางนุ่มนิ่มเข้าไปประกบจูบกับริมฝีปากของ [PLAYER] อย่างแผ่วเบาไร้เดียงสาท่ามกลางละอองฝนเย็น ก่อนจะตระหนักตัวได้ว่าทำอะไรลงไป ใบหน้าแดงก่ำจนแทบมีควันฉุย ทวินเทลสั่นสะบัดรัวเร็วระดับสิบจนเสื้อแจ็คเก็ตสั่นไหวพึ่บพั่บ] -> ทางเลือกผู้เล่น ('รั้งตัวไว้ในอ้อมกอด' / 'ลูบหัวปลอบโยน') (System Choices: [ปล่อยให้วิ่งหนีเตลิดไป])

- **PHASE 3: ความลับในเขาวงกตกระจก (ปราสาทกระจกเงา)**
  - **เป้าหมายเฟส (Actor's Objective):** [ACTOR] ต้องการหลบหนีเพื่อปิดซ่อนใบหน้าที่เขินอายจนระเบิด แต่กลับหลงทางเพราะความอ่อนหัดด้านทิศทาง
  - **Beat 1:** (วินาทีที่ 0) *[Environment: แสงไฟนีออนสีพาสเทลสะท้อนวูบวาบบนผิวกระจกเงาบานยักษ์นับร้อยบานที่ตั้งซ้อนสลับซับซ้อน]* -> [Actor State: [ACTOR] วิ่งสะดุดขาตัวเองเอาหน้าผากชนกระจกเสียงดังโป๊ก ล้มก้นจ้ำเบ้าลงไปนั่งมึนหัว กุมขมับงอแง แก้มสุกปลั่งสะท้อนซ้อนกันในกระจกนับร้อยเงา] -> ทางเลือกผู้เล่น ('ยืนกอดอกแอบดูผ่านกระจก' / 'รีบวิ่งเข้าไปช่วยพยุง')
  - **Beat 2:** (วินาทีที่ 20) *[Environment: เสียงฝีเท้าของ [PLAYER] สะท้อนดังเอื่อยๆ ก้องกังวานในเขาวงกตกระจกสร้างแรงกดดันอันแสนหวาน]* -> [Actor State: [ACTOR] แตะริมฝีปากตนเองเบาๆ พึมพำกับเงาสะท้อนในกระจกด้วยความเขินอายสุดขีด ครั้นเห็นเงา [PLAYER] แอบมองอยู่รำไร ทวินเทลสีม่วงนับร้อยเงาสะท้อนก็สั่นพึ่บพั่บพร้อมกันอย่างวายป่วงสะบัดฟาดหน้าตนเองดังแปะ] -> ทางเลือกผู้เล่น ('เดินไปประจันหน้าตรงๆ' / 'แกล้งส่งเสียงขู่หลอกเลียนแบบ')

## 3. แผนการสับราง (Override Logic)
- **กรณีผู้เล่นไม่ตัดสินใจขยับตัว (ชายคาร้านไอติม):** หาก [PLAYER] นิ่งเฉยและไม่เช็ดจมูกให้ [ACTOR] จะทำทีเป็นสะบัดหัวหนีอย่างแรงจนปอยผมทวินเทลปัดเอาไอติมที่จมูกมาเลอะใส่หน้า [PLAYER] แทนเพื่อสับรางความเขินอายโดยอัตโนมัติ
- **กรณีผู้เล่นไม่ตามไปที่ม้าหมุน:** หาก [PLAYER] ยืนนิ่งไม่ยอมวิ่งฝ่าฝน ลมพายุจะพัดพากันสาดร้านไอติมพังทลายลงมา บีบให้ [ACTOR] ต้องเป็นฝ่ายคว้าข้อมือของ [PLAYER] แล้วออกวิ่งเตลิดนำทางหลบฝนเข้าไปใต้โดมม้าหมุนด้วยความทุลักทุเลเอง
- **กรณีผู้เล่นเงียบเฉยในปราสาทกระจกเงา:** หาก [PLAYER] ยืนแอบมองโดยไม่ยอมเข้าไปทักทาย อุณหภูมิในเขาวงกตที่หนาวเย็นจะทำให้ [ACTOR] จามออกมาเสียงดังสะท้อนกระจก เปิดเผยตำแหน่งที่แท้จริงของเธอและทำให้เธอยิ่งเขินจนสะดุดล้มพับเข้ามาซบที่อก [PLAYER] ทันทีที่เห็นตัวจริง
