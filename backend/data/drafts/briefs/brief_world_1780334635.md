# THE MASTER BRIEF: WAR OF HEARTS IN STARRY LAND
## 0. บริบทความสัมพันธ์และแรงจูงใจ (Context & Motivations)
- **สถานะความสัมพันธ์:** คู่กัดวัยเด็กที่ต่างฝ่ายต่างรู้ดีว่ามีใจให้กัน แต่ตั้งกฎเหล็กลับๆ ร่วมกันโดยไม่พูดออกมาว่า "ใครสารภาพรักก่อน/ใครใจเต้นเขินอายก่อน คนนั้นแพ้"
- **ความลับที่ซ่อนอยู่:** [ACTOR] แอบวางแผนภารกิจพิสูจน์ความกล้าในวันนี้ โดยท้าทาย [PLAYER] ว่า *"ถ้าฉันทำให้ [PLAYER] เขินไม่ได้วันนี้ ฉันยอมให้ [PLAYER] แกล้งทั้งวันเลย"* แต่ความจริงแล้ว [ACTOR] กลับเป็นฝ่ายเก็บอาการไมู่อยู่และพร้อมจะสติหลุดเสียเองทุกครั้งที่โดนรุกกลับ
- **เหตุผลการแต่งกายและการแสดงออก:** [ACTOR] แต่งกายด้วยเสื้อสายเดี่ยวสีเขียวมินต์พาสเทลแต่งระบายพร้อมโบสีเขียวเข้มตรงอก และกางเกงยีนส์ขาสั้นแต่งขาดเพื่อความคล่องตัวในการเล่นเครื่องเล่นและโชว์ความมั่นใจ แต่เมื่ออากาศหนาวจากฝนตกและ [PLAYER] เอาเสื้อแจ็คเก็ตมาคลุมให้ [ACTOR] จะใช้เสื้อแจ็คเก็ตนั้นเป็นเกราะกำบังใบหน้าแดงก่ำของตัวเอง

## 1. แผนที่และผัสสะแวดล้อม (Spatial Map & Sensory)
- **รายชื่อสถานที่และการเชื่อมโยง:** 
  - ขั้นบันไดหินกลางป่าโปร่ง (จุดเริ่ม) -> [ทางเชื่อม: เส้นทางวิ่งฝ่าสายฝน] -> ชายคาหน้าร้านไอติมเรโทรขอบทอง -> [ทางเชื่อม: เส้นทางวิ่งฝ่าละอองฝนสลับลมหนาว] -> ม้าหมุนโบราณ (ใต้โดมเครื่องเล่น) -> [ทางเชื่อม: เส้นทางวิ่งเตลิดหลงทิศ] -> ปราสาทกระจกเงา (Mirror Maze) -> [ทางเชื่อม: ประตูทางออกด้านหลัง] -> จุดชมวิวชิงช้าสวรรค์ Starry Eye
- **แปลนและสภาพแวดล้อมบีบบังคับ (Environmental Pressure):**
  - **ชายคาร้านไอติม:** พื้นที่แคบใต้ชายคา มีละอองฝนสาดเทลงมาอย่างหนัก บีบให้ [ACTOR] และ [PLAYER] ต้องยืนเบียดชิดกัน ความหนาวเหน็บทำให้เกิดลมหายใจเป็นไออุ่น
  - **ม้าหมุนโบราณ:** ม้าไม้แกะสลักสีทองตัวแคบที่ต้องนั่งซ้อนท้ายเบียดกัน แสงไฟวอร์มไลท์สีส้มหมุนวนช้าๆ ท่ามกลางพายุฝนรอบด้านที่บดบังทัศนวิสัยภายนอกจนเหลือเพียงพื้นที่ของ [ACTOR] และ [PLAYER]
  - **ปราสาทกระจกเงา (Mirror Maze):** ทางเดินแคบที่เต็มไปด้วยกระจกเงาสะท้อนแสงนีออนพาสเทลร้อยแปดบาน ไม่มีจุดอับลมแต่มีความกดดันทางสายตา เนื่องจากกระจกเงาสะท้อนภาพแก้มแดงๆ และผมทวินเทลสั่นไหวของ [ACTOR] ซ้ำไปซ้ำมาจากทุกทิศทาง

## 2. โครงสร้างเหตุการณ์แบบอิสระ (Phases & Micro-Beats)

### PHASE 1: การท้าทายและการแย่งชิง (ขั้นบันไดหิน สู่ ชายคาร้านไอติม)
- **เป้าหมายเฟส (Actor's Objective):** [ACTOR] พยายามคุมเกมการเล่นงาน [PLAYER] ด้วยท่าทีทีเล่นทีจริง และพยายามแย่งไอติมเพื่อชัยชนะในเกมเดิมพัน
- **Beat 1:** (วินาทีที่ 0) [Director Cue: จู่ๆ ท้องฟ้ามืดครึ้มและฝนเทกระหน่ำโครมใหญ่ลงมาอย่างไม่มีปี่มีขลุ่ย] -> [Actor State: [ACTOR] สะดุ้งโหยงจนผมทวินเทลตั้งชัน รีบใช้มือป้องหัวแล้ววิ่งนำลิ่วหนีฝนมาที่ชายคากล่องดนตรีเรโทรของร้านไอติม หอบหายใจแฮ่กๆ พลางส่งยิ้มกริ่มท้าทาย "[PLAYER] วิ่งช้าเป็นบ้าเลย! อ่อนหัดจริงๆ นะ!"] -> ทางเลือกผู้เล่น (หมวดหมู่เจตนาสั้นๆ: 'แกล้งหยอก / บ่นเรื่องฝน / เช็ดน้ำฝนบนตัว')
- **Beat 2:** (วินาทีที่ 15) [Director Cue: [ACTOR] สั่งไอติมรส "มินต์ช็อกโกแลตอวกาศ" ของโปรด แต่พนักงานแจ้งว่าเหลือโคนสุดท้ายของวันและวางลงบนเคาน์เตอร์] -> [Actor State: [ACTOR] กระโดดตะครุบโคนไอติมทันทีพร้อมๆ กับมือของ [PLAYER] จังหวะนั้น [ACTOR] แอบเนียนใช้นิ้วมือเรียวเล็กของตัวเองทับและบีบกระชับหลังมืออุ่นๆ ของ [PLAYER] ไว้แน่นหนึบไม่ยอมปล่อย แสร้งทำเป็นยื้อแย่งโคนไอติมแต่ความจริงคือพยายามยื้อดึงยุดเวลาจับมือให้ยาวนานที่สุดเพราะหัวใจเต้นแรงจากการได้สัมผัสมือ [PLAYER] ตรงๆ ยิ่งยื้อไว้นานเท่าไหร่ ฝ่ามือของ [ACTOR] ก็ยิ่งร้อนผ่าวและเปียกชื้น หัวใจเต้นโครมครามจนปลายผมทวินเทลทั้งสองข้างสั่นระริกดุ๊กดิ๊กพริ้วไหวถี่ๆ [ACTOR] พยายามหลบสายตาสีมินต์กรีนที่สั่นไหว แสร้งโวยวายกลบเกลื่อน "ไอติมรสนี้ของฉันนะ! [PLAYER] ต้องสละสิทธิ์สิ ห้ามแย่งนะ!"] -> ทางเลือกผู้เล่น (หมวดหมู่เจตนาสั้นๆ: 'ดึงข้อมือเบาๆ / เนียนจับมือตอบ / แกล้งยื่นหน้าเข้าไปใกล้')
- **Beat 3:** (วินาทีที่ 30) [Director Cue: ไอติมเริ่มละลายหยดลงมาเนื่องจากอุณหภูมิความชื้น] -> [Actor State: จังหวะยื้อยุดทำให้ไอติมสีเขียวพาสเทลป้ายเข้าที่ปลายจมูกรั้นๆ ของ [ACTOR] เต็มเปา [ACTOR] ชะงักตาโต แก้มแดงแป๊ดทันตาเห็น ปลายผมทวินเทลสั่นดุ๊กดิ๊กพริ้วไหวรัวๆ [ACTOR] พูดเสียงสั่นเครือ "มอง... มองทำไมเล่า! หน้าฉันมีอะไรติดหรือไง! ห้ามขำนะตาบ้า!"] -> ทางเลือกผู้เล่น (หมวดหมู่เจตนาสั้นๆ: 'หัวเราะแซว / ใช้นิ้วเช็ดให้ / แย่งงับไอติมบนจมูก')
- **Beat 4:** (วินาทีที่ 45) [Director Cue: ลมหนาวพัดกรรโชกเข้ามาใต้ชายคาจน [ACTOR] ตัวสั่นสะท้านและจามออกมาเสียงเบาเหมือนลูกแมว] -> [Actor State: [ACTOR] พยายามกอดอกแน่นและทำเป็นเข้มแข็งกลบเกลื่อนความหนาว แต่ใบหน้ากลับแดงแจ๋และตัวสั่นเทาจนผมทวินเทลสะบัดพึ่บพั่บละล้าละลัง พยายามหาทางออกจากการโดนจับจ้องสายตา] -> *(System Choices: [ถอดเสื้อแจ็คเก็ตคลุมหัวให้ [ACTOR]] / [แกล้งเอานิ้วป้ายไอติมคืนแล้วแซวว่าแก้มแดง] / [ยืนนิ่งๆ ไม่ทำอะไรเลย])*
  - *Branch 1: [ถอดเสื้อแจ็คเก็ตคลุมหัวให้ [ACTOR]]* -> [Actor State: [ACTOR] สะดุ้งตัวลอย รีบคว้าขอบเสื้อแจ็คเก็ตดึงลงมาปิดหน้าจนมิด ส่งเสียงอู้อี้จากใต้เสื้อ "ทำอะไรของ [PLAYER] เนี่ย... มืดจะตาย... แต่... แต่มันก็อุ่นดีหรอกนะ..." ทวินเทลข้างในสั่นรัวดุ๊กดิ๊กฟ้องความเขินจนเสื้อแจ็คเก็ตปูดไปมา] -> ทางเลือกผู้เล่น (หมวดหมู่เจตนาสั้นๆ: 'ดึงฮู้ดล้อเลียน / โอบไหล่กันหนาว / จูงมือวิ่งฝ่าฝน') *(System Choices: [จูงมือวิ่งฝ่าฝนไปที่ม้าหมุน]* )

### PHASE 2: ม้าหมุนหยุดโลกและรอยจูบสายฟ้าแลบ (โดมม้าหมุนโบราณ)
- **เป้าหมายเฟส (Actor's Objective):** [ACTOR] พยายามระงับความเขินอายใต้เสื้อแจ็คเก็ต แต่กลับพ่ายแพ้ให้กับบรรยากาศจนเผลอแสดงความรู้สึกจริงในใจออกมา
- **Beat 1:** (วินาทีที่ 0) [Director Cue: ทางเดินเปียกน้ำฝนเจิ่งนองและลื่นมากขณะวิ่งฝ่าฝน] -> [Actor State: [ACTOR] ที่ก้าวขาไม่ทันเพราะมองทางไม่ถนัดใต้เสื้อคลุม สะดุดขาตัวเองซวนเซเข้ามาชนหลัง [PLAYER] ดัง *ปึ้ก!* สองมือเล็กๆ ขยี้เสื้อ [PLAYER] ไว้แน่นหนึบ ส่งเสียงร้องลนลาน "วิ่งช้าๆ หน่อยเซ่! ฉันตามไม่ทันนะ!"] -> ทางเลือกผู้เล่น (หมวดหมู่เจตนาสั้นๆ: 'อุ้มเดิน / จับมือให้แน่นขึ้น / หยุดเดินแกล้ง')
- **Beat 2:** (วินาทีที่ 20) [Director Cue: เด็กสองคนวิ่งผ่านหน้าเครื่องเล่นม้าหมุนและมือไปโดนสวิตช์เปิดเครื่องเล่นจนระบบหมุนทำงานพร้อมแสงไฟสีทองสว่างวาบขึ้น] -> [Actor State: [PLAYER] ดึง [ACTOR] ขึ้นไปนั่งซ้อนบนม้าไม้ตัวเดียวกัน ม้าหมุนขยับขึ้นลงช้าๆ [ACTOR] เสียหลักหงายหลังแนบชิดกับอกของ [PLAYER] [ACTOR] ตัวเกร็ง หัวใจดวงน้อยเต้นโครมครามกระแทกแผ่นหลัง [PLAYER] อย่างปิดไม่มิด [ACTOR] หันหน้ามาสบตาในระยะห่างไม่กี่เซนติเมตร พึมพำเสียงสั่น "งะ...งื้อออ! ห้ามปล่อยมือนะ... เดี๋ยวฉันตก..."] -> ทางเลือกผู้เล่น (หมวดหมู่เจตนาสั้นๆ: 'กอดเอวกระชับ / กระซิบข้างหู / จ้องมองตา')
- **Beat 3:** (วินาทีที่ 40) [Director Cue: เสียงเพลงกล่องดนตรีบรรเลงเพลงคลาสสิกหวานซึ้งคลอไปกับเสียงฝนตกด้านนอก] -> [Actor State: [ACTOR] ตกอยู่ในภวังค์ความรักที่ล้นอก สายตาของ [ACTOR] จ้องมองริมฝีปากของ [PLAYER] สลับกับดวงตาอย่างไร้เดียงสา ก่อนที่ [ACTOR] จะเผลอขยับริมฝีปากเลื่อนเข้าไปประกบจูบ [PLAYER] อย่างแผ่วเบาและเนิ่นนานท่ามกลางแสงไฟหมุนวน] -> ทางเลือกผู้เล่น (หมวดหมู่เจตนาสั้นๆ: 'จูบตอบอย่างอบอุ่น / กอดลูบหลัง / ยืนนิ่งด้วยความตะลึง')
- **Beat 4:** (วินาทีที่ 60) [Director Cue: ม้าหมุนเริ่มลดความเร็วลงจนใกล้หยุดนิ่ง] -> [Actor State: หลังถอนริมฝีปาก [ACTOR] เพิ่งได้สติว่าตัวเองรุกก่อน แก้มระเบิดสีแดงก่ำจนแทบมีควันฉุย ผมทวินเทลสั่นสะบัดพึ่บพั่บรัวเร็วปานใบพัดเฮลิคอปเตอร์จนเสื้อแจ็คเก็ตขยับไหว [ACTOR] ผลักอก [PLAYER] เบาๆ แล้วหันหลังโกยอ้าววิ่งหนีเตลิดเปิดเปิงทันที] -> ทางเลือกผู้เล่น (หมวดหมู่เจตนาสั้นๆ: 'วิ่งตามไป / ตะโกนเรียก / ยืนขำคนเดียว') *(System Choices: [วิ่งตามเข้าไปในปราสาทกระจกเงา]* )
